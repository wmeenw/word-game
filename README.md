# Игра в слова

Домашнее задание 1 курса по Java. Консольная игра, в которой нужно угадывать слова из выбранной категории.

## Что сделано в качестве ДЗ

- Словарь слов, разбитых по категориям (`Words`, `Category`).
- Уровни сложности (`TypesOfDifficulties`).
- Игровая сессия: выбор категории, ход игры, подсчёт результата (`GameSession`).
- Вывод игрового поля и сообщений в консоль (`Visualisator`).

## Запуск

Откройте проект в IntelliJ IDEA (файл `homework1.iml`) и запустите `Main`.

Исходный код: ветка `homework1` репозитория [wmeenw/JAVAhomework](https://github.com/wmeenw/JAVAhomework).

# Word Game («Виселица»)

Консольная игра «Виселица» на Java. Игрок угадывает слово по буквам из выбранной категории, у него ограниченное число попыток и одна подсказка.

Домашнее задание 1 по Java.

## Возможности

- **Игра по умолчанию** — слово, категория, уровень сложности и подсказка выбираются автоматически.
- **Пользовательская игра** — вы загадываете слово (минимум две буквы), выбираете уровень сложности и вводите подсказку.
- **Три уровня сложности** с разным числом попыток:

| Уровень | Попытки |
|---------|---------|
| `Easy`   | 6 |
| `Normal` | 7 |
| `Hard`   | 8 |

- Одна подсказка на игру, привязанная к категории слова.
- Вывод параметров игры и состояния поля в консоль.

## Структура

```
homework1/src/
├── Main.java               точка входа, правила, режимы игры
├── Words.java              словарь и выбор слова, сложности, подсказки
├── Category.java           категории слов
├── TypesOfDifficulties.java уровни сложности (Easy, Normal, Hard)
├── GameSession.java        ход игры: ввод букв, попытки, победа/поражение
├── Visualisator.java       вывод поля и сообщений
└── ...
```

## Требования

- JDK 17 или новее.
- IntelliJ IDEA (проект создан как модуль IDEA, файл `homework1.iml`).

## Запуск

1. Откройте папку репозитория в IntelliJ IDEA.
2. Запустите `Main` из `homework1/src`.
3. В консоли нажмите **Enter**, чтобы начать игру по умолчанию, или введите слово для пользовательской игры.

Пример сессии:

```
Введите задуманное слово или нажмите ENTER, если хотите продолжить с игрой по умолчанию
Ваш выбор:
(Enter)
-------- Параметры игры --------
Уровень сложности: Normal
Количество попыток: 7
Длинна слова: 8
--------------------------------
```

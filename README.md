# Домашнее задание 1 — игра в слова

Игра, в которой нужно угадывать слова из выбранной категории. Классы: `Words` (словарь), `Category` (категории), `TypesOfDifficulties` (уровни сложности), `GameSession` (ход игры), `Visualisator` (вывод в консоль).

## Запуск

Откройте проект в IntelliJ IDEA (файл `homework1.iml`) и запустите `Main`.

Исходный код взят из ветки `homework1` репозитория [wmeenw/JAVAhomework](https://github.com/wmeenw/JAVAhomework).
